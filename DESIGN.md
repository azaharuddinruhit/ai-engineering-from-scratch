# Design System: AI Engineering from Scratch

## Overview

**Creative North Star: "The Annotated Plot"**

Every lab in this course is a chart: a probability distribution, a chunk-size histogram, an embedding scatter, a recall curve. The design system treats the whole site the same way. The palette is drawn from viridis, the default colour map of scientific plotting, and colour is spent on data: the bars, the highlighted values, the verdicts. Everything around the data is annotation, set in a calm, engineered sans that a working engineer can read for twenty-five minutes with an editor open beside it.

The surface is a reading surface first. Lessons are long, so the prose is generous (18px sans on wide screens, about 75 characters a line) and the chrome recedes: hairline borders, cool neutral greys, no ornament. Controls are quiet and small; when a learner moves one, the change shows up loudly in the plot it drives. The home page earns its one moment of theatre the same way: the opening sentence is generated by a live sampler, and the token that was drawn is marked in yellow.

Density is moderate. Docs pages use the familiar three columns (curriculum, article, contents) because learners already know how to navigate them; distinctiveness lives in type, colour discipline and the labs, not in novel navigation.

**Key Characteristics:**
- Viridis palette: violet ink, plot teal, drawn yellow, cool graphite neutrals.
- One sans (IBM Plex Sans) for reading and interface; one mono (JetBrains Mono) only for code, numbers and measurements.
- Quiet controls, loud data.
- Flat surfaces with hairline borders; one soft shadow lifts interactive labs off the page.
- Light and dark themes are equal citizens; every token has a dark counterpart.

## Colors

A scientific-plotting palette: one violet ink, one teal accent, one yellow for the value that was chosen, over cool graphite neutrals.

### Primary
- **Plot Teal** (#1d7a74): the accent. Links, primary buttons, the focus ring, the current page in navigation, available modules on the curriculum path, and the plotted bars in labs. White text on it passes AA. Hover deepens to **Plot Teal Deep** (#17625d); dark mode uses **Plot Teal Bright** (#3fafa3) for text and lines. **Plot Teal Mist** (#eaf6f4) tints production-tip callouts and the focused steps of flow diagrams.

### Secondary
- **Drawn Yellow** (#f2d21b): the value that was chosen. The drawn token in the hero and samplers, query terms matched in retrieved text, chunk overlap, the answer document, and text selection. Always paired with Viridis Ink text, in both themes.

### Tertiary
- **Viridis Ink** (#2a0b45): headings, titles and bold text in light mode, plus the logo square. In dark mode headings switch to **Viridis Ink Inverse** (#f1ecf8). It reads as near-black with a violet cast, tying the type to the palette without becoming a second accent.

### Neutral
- **Paper** (#ffffff) / **Paper Dark** (#13161d): page and lab-frame backgrounds.
- **Inset** (#f7f8fa) / **Inset Dark** (#1b1f28): lab headers, callouts, inputs, the "mark as complete" panel, segmented-control tracks.
- **Hairline** (#dfe2e9) / **Hairline Dark** (#282c37): every border and divider.
- **Body Text** (#282c37) / **Body Text Dark** (#dfe2e9): lesson prose and interface text.
- **Secondary Text** (#4f5566): descriptions, summaries, lab copy.
- **Muted Text** (#6a7080) / **Muted Text Dark** (#99a0ae): captions, hints, metadata. Exposed as the `text-muted` utility; it is the lightest grey allowed for text.

### Verdicts
- **Verdict Pass** (#047857), **Verdict Fail** (#e11d48), **Verdict Caution** (#92400e): lab outcomes (found / missed, supported / unsupported, passed / failed) and warning callouts. Always paired with a drawn icon or a word, never colour alone.

### Named Rules
**The Drawn Yellow Rule.** Yellow marks exactly one thing: a value that was chosen, drawn or matched. Never a button, a background panel, a heading or decoration. If nothing was chosen, nothing is yellow.

**The Data Gets the Colour Rule.** Saturated colour belongs to plots, highlights and verdicts. Chrome (headers, sidebars, panels, borders) stays graphite. If a control is more colourful than the value it changes, it is wrong.

**The 4.5 Floor Rule.** No text is lighter than Muted Text on its background (4.5:1 in both themes). Grey text on a grey fill steps up to Secondary Text.

## Typography

**Display Font:** IBM Plex Sans (with system-ui, sans-serif)
**Body Font:** IBM Plex Sans (with system-ui, sans-serif)
**Label/Mono Font:** JetBrains Mono (with ui-monospace, Menlo, Consolas)

**Character:** An engineer's grotesque with squared curves and open counters carries everything people read, from the 88px title to 13px sidebar labels; the mono appears only where a value is measured or computed. Plex Sans and JetBrains Mono share a technical temperament, so prose and code read as one voice, like a well-made engineering handbook with live figures.

### Hierarchy
- **Display** (600, 5.5rem on wide screens, 4.5rem tablet, 2.75rem phone, line-height 0.95, -0.025em): the home page title only, set on two fixed lines.
- **Headline** (600, 3rem, line-height 1.05, -0.02em, balanced wrapping): lesson and module titles.
- **Title** (600, 1.875rem, line-height 1.2): home page section headings; lesson h2s come from the prose scale.
- **Lede** (400, 1.75rem, line-height 1.45): the hero's generated sentence and, at 1.25rem, lesson descriptions under the title.
- **Body** (400, 1.125rem on wide screens and 1rem below, line-height 1.78, about 75ch measure): lesson prose; interface text uses 0.875–1rem.
- **Label** (600, 0.8125rem, sentence case): sidebar module names, "On this page", lab section titles.
- **Data** (JetBrains Mono 400, 0.75rem, tabular figures): slider readouts, probabilities, stats, token text; code blocks at 0.8125rem.

Italic carries secondary voice: module taglines, playground names, worked examples.

**Math** is written in TeX and set by KaTeX at build time, in KaTeX's own serif math faces at 1.1em so it sits level with Plex Sans. Inline formulas stay in the sentence; display equations stand on their own line and scroll sideways on narrow screens rather than widening the page.

### Named Rules
**The Sans Reads, Mono Measures Rule.** If a learner reads it, it is sans. If it is a number, token, identifier or code, it is mono. Mono is never used to make a label look technical.

**The No Shouting Rule.** No uppercase labels, no tracked-out eyebrows above headings. A heading carries its own weight; supporting context goes below it in italic or muted text.

## Layout

The site uses a 4px spacing base. The sticky header is 56px. Docs pages are three columns inside a 90rem container: a 288px curriculum sidebar from 1024px, an article capped at 48rem, and a 224px "On this page" list from 1280px. Below 1024px the sidebar becomes a full-screen panel behind a menu button.

The home page uses a 72rem container. Sections pair a 20rem heading column with a flexible content column from 1024px, and stack below it. Sections are separated by 80px; inside labs, groups sit 32px apart with 20px of frame padding. Related items are grouped tightly (4–8px) and distinct groups generously.

Sequences are drawn as sequences: the curriculum is a vertical path of numbered nodes joined by a line, and lesson lists on module pages are numbered rows separated by hairlines. Neither uses a grid of identical cards.

On phones every lab control goes full width, segmented controls stretch their options so wrapped rows stay balanced, and the 16px side gutter never scrolls horizontally.

## Elevation & Depth

The system is flat. Depth comes from tonal layering (Paper over Inset) and hairline borders, not shadows. One soft shadow exists: lab frames and the checked option of a segmented control carry a small shadow (`0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1)`) so interactive surfaces sit a hair above the reading surface. The sticky header uses an 85%-opaque background with a backdrop blur, which is functional (text scrolling beneath stays legible), not decorative.

### Named Rules
**The Flat-By-Default Rule.** Static content never casts a shadow. Only things a learner manipulates get the one soft lift.

## Shapes

Corners are gently rounded and step down as elements nest: lab frames and the hero panel at 12px, callouts, code blocks, failure modes and pager links at 8px, buttons, inputs and segmented options at 6px, badges and yellow marks at 4px. Curriculum nodes, slider thumbs and probability-bar tracks are fully round. Borders are always 1px hairlines; dashed hairlines mean "not yet" (upcoming topics, the chunk-size limit line). Arrows and status marks are drawn SVG with round caps at a 2–2.5 stroke.

## Components

### Buttons
Quiet, compact, and named by their action ("Start Module 1", "Draw again", "Mark as complete").
- **Shape:** gently rounded (6px).
- **Primary:** Plot Teal fill, white semibold text, 10px × 20px on pages and 6px × 12px inside labs.
- **Hover / Focus:** fill deepens to Plot Teal Deep; keyboard focus shows a 2px teal outline offset by 2px.
- **Secondary:** paper fill, 1px graphite border, body text; hover fills with Inset.
- **Pressed toggle:** "Mark as complete" turns Verdict Pass green and reads "Completed".
- **Disabled:** 50% opacity, not-allowed cursor.

### Chips
- **Query presets and suggestions:** rounded-full outline chips in secondary text; the active one gets a teal border, Plot Teal Mist fill and teal text.
- **Verdict badges:** 4px-rounded tinted fills (green, rose, amber) with a drawn check, cross or dash icon and a word.
- **"Coming soon":** small Inset badge in Secondary Text.

### Cards / Containers
- **Lab frame:** 12px corners, Paper background, hairline border, the one soft shadow. An Inset header holds the lab title (Viridis Ink, 18px semibold) and a one-line description, with no label above it.
- **Callouts:** 1px full border with a tinted fill: Note on Inset, Production tip on Plot Teal Mist, Warning on amber. Never a thick side bar.
- **Failure modes:** hairline-bordered 8px panels with a rose warning icon, the title, the observed symptom, then Why and Mitigation.
- **Internal padding:** 20px.

### Inputs / Fields
- **Style:** Inset fill, hairline border, 6px corners, 14px text; placeholders meet the 4.5:1 floor.
- **Sliders:** native range inputs tinted Plot Teal, with a mono readout right-aligned on the label row.
- **Segmented control:** an Inset track with 6px options; the checked option is Paper with the soft shadow and Viridis Ink text. It is a radio group, so arrow keys work.
- **Focus:** 2px teal outline, 2px offset, on every interactive element.

### Navigation
- **Header:** the logo mark (a three-bar distribution on a Viridis Ink square, the tallest bar Drawn Yellow) plus the name in semibold on one line, and the theme toggle on the right. Nothing else; the curriculum is reached through the sidebar and the home page.
- **Sidebar:** sentence-case module headings in Viridis Ink (upcoming ones muted with a "Coming soon" badge), lessons as a list with a 1px left rule; the current lesson takes a teal rule and teal text; completed lessons show a drawn check.
- **On this page:** muted links that turn teal on hover.
- **Pager:** two hairline cards with drawn chevrons and the lesson title in Viridis Ink.

### Live Sampler (signature)
The home page's opening sentence is generated live by a scripted next-token model. Each word is a button (arrow keys move between them). Words that were not the most likely choice wear Drawn Yellow. A side panel lists the candidates for the focused word as teal probability bars, with the drawn one in yellow, under a temperature slider with Draw again and Reset. On load, and after each new draw, a yellow highlighter sweeps once across the words (520ms each, `cubic-bezier(0.16, 1, 0.3, 1)`, staggered 70ms). It is skipped when the visitor prefers reduced motion, and it is the only autonomous motion on the site.

## Do's and Don'ts

### Do:
- **Do** spend colour on data: probability bars, highlights and verdicts carry the palette, chrome stays graphite.
- **Do** mark the chosen, drawn or matched value with Drawn Yellow (#f2d21b) and Viridis Ink text, and nothing else.
- **Do** set reading text in IBM Plex Sans and every number, token and code sample in JetBrains Mono.
- **Do** write formulas as TeX (`$…$` inline, `$$…$$` display), not as inline code or a text code block.
- **Do** use `text-muted` (#6a7080 / #99a0ae) as the lightest text colour, and Secondary Text on grey fills.
- **Do** draw sequences as paths or numbered rows (curriculum, lesson lists, lesson parts).
- **Do** give every colour-coded state a drawn icon or a word as well.
- **Do** define every new colour for both light and dark themes.

### Don't:
- **Don't** put an uppercase or tracked-out label above a heading.
- **Don't** join metadata with middle dots or append "→" to button and link text.
- **Don't** use Unicode glyphs (✓, ✕, →) as icons; draw them as SVG.
- **Don't** give callouts or cards a thick coloured side border.
- **Don't** use yellow for buttons, backgrounds or decoration.
- **Don't** lay out a sequence as a grid of identical cards.
- **Don't** add entrance animations to sections; the live sampler's sweep is the only autonomous motion.
